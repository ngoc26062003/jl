# N5 vocabulary data notice

`vocab_n5.csv` contains the 674-word N5 vocabulary set from [OpenJLPT](https://github.com/evanclan/OpenJLPT), version 0.3.0, distributed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). The data is based on Jonathan Waller's community JLPT lists and JMdict (EDRDG); the N5 level is an unofficial approximation, not an official JLPT list.

The Vietnamese glosses are machine translations of OpenJLPT's English glosses. The data file and these translations are distributed under CC BY-SA 4.0. OpenJLPT's source and attribution details are available in its [NOTICE](https://github.com/evanclan/OpenJLPT/blob/main/NOTICE.md).
